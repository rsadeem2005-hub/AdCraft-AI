# AdCraft AI (v2)
Write ad copy for five platforms from one brief. Pick an angle, get three variants per platform, see live character counts and ad previews, star your favourites into a swipe file, and export them.

## How it works
Copy is built by a **template engine in your browser**, not by a live AI model. It chooses wording that fits each platform's limit and flags anything too long. Use "Copy AI prompt" to polish a variant in any AI tool.

Character limits are common guidelines. Always check each platform's current rules before running ads.

## Run
`npm install` then `npm run dev`. Build with `npm run build`. Deploy with Vercel or `npm run deploy` for GitHub Pages.

## Customize
Edit the `H` (headlines), `B` (body) and `PL` (platforms and limits) objects at the top of `src/App.jsx`.
